# Small learner comparison

This is a protocol and blank worksheet, not completed research. Use one safe,
self-filmed tabletop task with a clear observable result and two or three distinct
props. The purpose is to find whether the coach improves learning enough to justify
its setup and waiting time. Synthetic browser tests do not answer that question.

1. Recruit three to five beginners unfamiliar with the task; use anonymous IDs.
   Explain the camera/model request and obtain their agreement before testing.
2. Use two comparable task variants. Counterbalance which variant/tool is first;
   do not have everyone learn the identical task in control before using the app.
3. Control: ordinary tutorial plus written checklist. Coach: the same quality of
   reference material with Reel2Real. Use the same device/workspace where practical.
4. Start timing before setup. Record setup, model waits, task time, video
   interruptions/scrubs and requested help. Include failures and abandoned runs.
5. Judge the physical result using a fixed task-specific rubric independently of
   the app's object labels. Object visibility is not an action-quality measurement.
6. Ask what helped, what confused them, and ease on a consistent 1–5 scale. Record
   their words accurately; ask permission before quoting them externally.

Use the [blank CSV](evidence/learner-trial-template.csv). All duration fields are
seconds. Leave missing observations blank and explain why. Keep results local until
reviewed; do not put identifiable participant data in the public repository.

For a tiny sample, report individual outcomes and medians descriptively. State the
number of people/runs, devices, task, order, failures and limitations. Avoid causal
or population-wide claims, statistical significance claims, or a “time saved”
percentage that omits setup/model waits. If no study runs, say it remains unrun.

Submission-ready observation format:

> On [task], [n] beginners completed [actual number] runs on [device]. Including
> setup and waits, [observed comparison]. [Failure/limitation]. These observations
> are exploratory; they do not establish general learning or safety benefits.
