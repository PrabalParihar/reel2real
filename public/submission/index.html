What runs in the demo

  • A recorded lesson with saved instructions, saved SAM output and creator credit.
  • A real Muse Spark API call planning a complete, owned six-second generated clip, including its later blue-card step.
  • Real SAM checks from a virtual camera: missed objects in one run; a red-paper box and fresh recheck in a separate goal-plus-still run.
  • Next, Skip and a recap that preserve the learner’s choices.

Current boundaries

  • Detection can miss visible objects. These test runs include missed card/tray and paper edge/corner checks.
  • An object box does not verify the action, technique, order or general safety.
  • This is a generated-media test, not physical learner footage. Phone trials, useful physical-task correction and learner outcome studies remain to be done.
  • Recorded Samples replay supplied results; they do not make live inference calls.
