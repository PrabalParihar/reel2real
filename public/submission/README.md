# Submission demo media

This directory contains an original edited screen recording of the hosted Reel2Real prototype. It is public judge-facing material, not a submission receipt.

- `reel2real-demo.mp4`: 123 seconds, 1920×1080 H.264/AAC, English synthetic narration and burned-in captions.
- `captions.vtt` / `captions.srt`: optional English captions.
- `transcript.txt`: spoken narration.
- `poster.png`: original Reel2Real title graphic.
- `index.html`: native video player, app/source links, evidence boundaries and credits.

The edit combines a recorded Sample, an uploaded procedural six-second lesson, and a **separate** goal-plus-still run with a red-square virtual camera. Those transitions and result provenance are labelled. One approximately 17-second planning wait is shortened explicitly. There are no intercepted/replaced model responses. No physical learner or phone study is shown.

The clip run did not highlight its visible cards/tray. In the separate goal run, the red-paper object was localized on three actual checks, while paper edge/corner were not highlighted. These results do not establish general accuracy, physical-task correction or learning gains. Next records learner confirmation rather than autonomous action verification.

Procedural QA media and title/diagram graphics were made for this project. The narration is synthetic flite SLT. The recorded chai lesson and visible gallery imagery preserve their actual stock sources and licences; see [the sample credits](../samples/CREDITS.md). Stock footage is not self-filmed.

The narrow MP4 exception in `.gitignore` is for this original edited screencast. Private creator uploads and raw capture files stay outside the repository.
