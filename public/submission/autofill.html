Reel2Real demo

Fill your Meta submission.

Install this small bookmark once, then run it in your existing signed-in submission tab. It fills the prepared answers without copying each field separately.

  1. In desktop Chrome, show the bookmarks bar with Ctrl + Shift + B (Mac: ⌘ + Shift + B).
  2. Drag this blue link onto that bar:
    Fill Reel2Real

  3. Return to the open Cerebral Valley submission form and click the saved Fill Reel2Real bookmark. A report on that page tells you which fields were filled or need attention.

Keep your existing form open so its unsaved entries stay there. Clicking the blue link on this helper page will not fill another tab—save it to the bookmarks bar and run it in the submission tab.

What it fills

Blank project description, GitHub repository, demo video, Meta product usage, why the models matter, and factual partner-technology feedback. Existing text, team members, track, problem statement, ratings and declarations are preserved.

It does not submit the form or create a remote browser connection. It does not read passwords, cookies or tokens, and does not send your form contents to our server. The portal can respond normally to input changes.

The video is our real 2:03 MP4. A YouTube placeholder does not establish host validation. If the portal requires YouTube, upload the MP4 and use its actual link.

Code and prepared answers

The bookmark is self-contained and restricted to this Meta event's submission/edit path. Missing, ambiguous, read-only and invalid fields are reported. Actual private-page compatibility is not established by local fixture tests.
